Direction-Scale Decomposition

Direction-Scale Decomposition in Action Representation: Rethinking What to Tokenize for Vision-Language-Action Models

DSD separates magnitude and direction before tokenization, making discrete action patterns more reusable across collection speeds, normalization statistics, and robot datasets.

Explore the methodWatch the overview

Three-minute anonymous project overview

Abstract

Action patterns should survive changes in scale

Standard action tokenizers normalize each action component before assigning it to a discrete bin. The resulting token sequence can change when a demonstrator moves faster, when dataset statistics shift, or when a model transfers to a new robot dataset. Direction-Scale Decomposition represents translation as direction and magnitude, and relative rotation as axis and angle. Dataset-dependent scale changes are isolated, while geometric action patterns remain stable.

Motivation

Normalization entangles motion with dataset statistics

The same intended movement can produce different action tokens for reasons unrelated to the underlying motion pattern.

01

Collection speed

A teleoperator follows the same path at a different speed, so the trajectory visits different magnitude bins.

02

Different statistics

The same raw action can be assigned to different bins under different normalization statistics.

03

Cross-dataset transfer

A model trained with Dataset A can produce distorted 3-D motion when Dataset C statistics denormalize its predicted tokens.

Method

Separate magnitude and direction before tokenization

DSD converts each 3-D translation into a magnitude and unit direction, and each relative rotation into an angle and unit axis. The gripper action remains unchanged.

Magnitude

Unit direction

nₚ = p / sₚ if sₚ > 0; e₃ otherwise
Relative rotation

Convert RPY to axis-angle

R = Rz(Δyaw) Ry(Δpitch) Rx(Δroll) → ω

Angle

sᵣ = ‖ω‖₂

Unit axis

nᵣ = ω / sᵣ if sᵣ > 0; e₃ otherwise
Why it works

Normalization changes scale while direction stays fixed

Different statistical ranges can move the magnitude into a new bin. The unit direction remains aligned, preserving the 3-D action pattern.
