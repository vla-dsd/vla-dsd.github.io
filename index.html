Direction-Scale Decomposition in Action Representation: Rethinking What to Tokenize for Vision-Language-Action Models

DSD separates direction from scale before tokenization, exposing a shared geometric convention across collection speeds, normalization statistics, and robot datasets.

Three-minute anonymous project overview

Abstract

Action representation matters before tokenization begins

Conventional pose-increment tokens are sensitive to execution speed and dataset-specific normalization, which can obscure structure shared across demonstrations. DSD decomposes translation into unit direction and magnitude, and relative rotation into unit axis and angle. It improves average success with BIN and BEAST on LIBERO, raises mixed-data SimplerEnv success by 10.3 percentage points over BIN, and improves real-robot performance with and without robotics pretraining.

Method

Separate direction and scale before tokenization

DSD converts each 3-D translation into a magnitude and unit direction, and each relative rotation into an angle and unit axis. The gripper action remains unchanged.

Raw action7 components[Δpₓ, Δpᵧ, Δpᶻ, Δroll, Δpitch, Δyaw, g]
›
DSD action9 components[sₚ, sᵣ, g, nₚˣ, nₚʸ, nₚᶻ, nᵣˣ, nᵣʸ, nᵣᶻ]
›
TokenizerDiscrete tokens256 bins per continuous coordinate
3-D translation

Magnitude

sₚ = ‖p‖₂

Unit direction

nₚ = p / sₚ if sₚ > 0; e₃ otherwise
Relative rotation

Convert RPY to axis-angle

R = Rz(Δyaw) Ry(Δpitch) Rx(Δroll) → ω

Angle and unit axis

sᵣ = ‖ω‖₂; nᵣ = ω / sᵣ if sᵣ > 0; e₃ otherwise
Normalization rule

Direction and axis already lie in [−1, 1] and receive no dataset-specific normalization. Scale channels use shared parameters during co-training and target-specific parameters during fine-tuning.

Why it works

Positive scale changes preserve direction

DSD makes this invariance explicit. A longer or shorter displacement changes the scale channel, while its unit direction stays the same.

same 3-D direction
αp / ‖αp‖₂ = p / ‖p‖₂   for α > 0

Magnitude may change across speed or scale calibration; the direction token target does not.
